Проект №1. Очистка и подготовка прайс-листов
Задача:
Ежедневно и многократно требовалось обрабатывать прайс-листы: удалять шапку, лишние столбцы, фильтровать данные и форматировать таблицу для ручной выбивки заказа в CRM-систему MobyC.

Решение:
Разработан макрос Очистка_Прайса, который автоматически выполняет все действия за 5 секунд.

Шаг	Действие	Результат
1	Удаляет строки 1–10	Остаются только данные
2	Проверяет столбец G на наличие формул	Если есть — удаляет столбец G
3	Удаляет столбцы D и E	Убирает единицы измерения и пустые столбцы
4	Сокращает ширину столбца B на 25%	Компактное отображение артикулов
5	Отключает перенос текста в столбце B	Текст не переносится, если не влезает
6	Удаляет пустые строки в столбце D	Остаются только строки с отметками
7	Автоподбор ширины столбца D	Чёткое отображение отметок
8	Масштаб 150%	Удобный просмотр
9	Выравнивает цены в столбце C по правому краю	Стандартный формат цен
10	Курсор на B2, обзор на A1	Готовность к работе, видна вся таблица
11	Сообщение в статусной строке	Информирование о завершении
Горячая клавиша: Ctrl + Shift + L (Win) / Cmd + Shift + L (Mac)

Результат:

✅ Время обработки: 2 минуты → 5 секунд

✅ Ручных действий: 11 шагов → 1 шаг

✅ Экономия: до 1 часа в неделю

Проект №2. Выделение акций и новинок в прайс-листах
Задача:
После подготовки прайс-листа требовалось:

Удалить товары с эксклюзивным контрактом ("Мит Гарден")

Выделить акционные товары жёлтым цветом

Выделить новинки (бренды: Монопротеин Стерил, Оптином, ПроШейп) зелёным цветом

Сохранить файл и закрыть Excel

Решение:
Разработан макрос Выделение_акций, который автоматически выполняет все действия за 3 секунды.

Условие	Действие	Цвет
"Мит Гарден" в столбце B	Удалить строку	—
Столбец C пустой	Пропустить (не выделять)	—
Столбец C = 21261016 или 00175	Пропустить (не выделять)	—
"бест диннер монопротеин" в столбце B	Пропустить (не выделять)	—
"УПАК" в столбце B	Пропустить (не выделять)	—
Монопротеин Стерил, Оптином, ПроШейп	Выделить ячейку B	🟩 Светло-зелёный
"акция" / "АКЦ" / "АК " в столбце B или C	Выделить ячейку B	🟨 Жёлтый
Сохранение файла	Без изменения имени	—
Закрытие Excel	Автоматически	—
Горячая клавиша: Ctrl + Shift + K (Win) / Cmd + Shift + K (Mac)

Результат:

✅ Время обработки: 3–4 минуты → 3 секунды

✅ Ручных действий: 7 шагов → 1 шаг

✅ Экономия: до 5 часов в неделю

Проект №3. Подготовка отчёта по дебиторской задолженности
Задача:
Регулярно требовалось обрабатывать файл с дебиторской задолженностью:

Удалять служебные строки и лишние столбцы

Удалять закрытых клиентов

Оставлять только корректные суммы долга (в диапазоне от -28 до 30)

Визуально выделять все положительные долги

Решение:
Разработан макрос Обработка_Дебиторки, который автоматически выполняет все действия за 3 секунды.

Шаг	Действие	Результат
1	Удаляет строки 1–3	Остаются только данные с заголовками
2	Удаляет столбцы B, D, E, G	Остаются нужные столбцы
3	Удаляет закрытых клиентов по списку	Исключение клиентов с эксклюзивным контрактом
4	Удаляет строки с C < -28 или C > 30	Остаются только корректные суммы долга
5	Выделяет строки (A, B, C) светло-красным, если C > 0	Визуальное выделение всех клиентов с долгом
6	Подгоняет ширину столбца B	Удобный просмотр
7	Масштаб 150%	Комфортная работа с отчётом
8	Курсор на A1	Готовность к работе
Список закрытых клиентов: Б2693, 01063, A1001, A0145, 03665, Б6926, Б7092, 03286, 05752

Горячая клавиша: Ctrl + Shift + J (Win) / Cmd + Shift + J (Mac)

Результат:

✅ Время обработки: 5–7 минут → 3 секунды

✅ Ручных действий: 8 шагов → 1 шаг

✅ Экономия: до 25 минут в неделю

Проект №4. Обработка прайса (выделение новинок и акций)
Задача:
В прайс-листе требовалось:

Заменить поиск "Джавс" на новые бренды: Монопротеин Стерил, Оптином, ПроШейп

Выделить новинки зелёным цветом

Выделить акции жёлтым цветом

Учитывать различные варианты написания "акция" (АКЦИЯ*, АКЦ, АК)

Не выделять слова "абстракция" и "фракция"

Не выделять "Бест Диннер Монопротеин" и "УПАК"

Решение:
Разработан макрос Прайс_Прусакова с расширенной логикой поиска.

Условие	Действие	Цвет
"бест диннер монопротеин" в столбце B	Пропустить (не выделять)	—
Столбец C = 21261016, 00175 или 175	Пропустить (не выделять)	—
"УПАК" в столбце B	Пропустить (не выделять)	—
Монопротеин Стерил, Оптином, ПроШейп	Выделить ячейку B	🟩 Светло-зелёный
"акция" в любом регистре	Выделить ячейку B	🟨 Жёлтый
"АКЦ" только заглавными буквами	Выделить ячейку B	🟨 Жёлтый
"АК " заглавными с пробелом в конце	Выделить ячейку B	🟨 Жёлтый
"абстракция" или "фракция"	Пропустить (не выделять)	—
Горячая клавиша: Ctrl + Shift + M (Win) / Cmd + Shift + M (Mac)

Результат:

✅ Время обработки: 2–3 минуты → 3 секунды

✅ Точность выделения: 100% (исключены ложные срабатывания)

✅ Экономия: до 3 часов в неделю
