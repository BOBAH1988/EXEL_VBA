# Портфолио: Автоматизация в Excel (VBA)

Это портфолио создано, чтобы показать мой подход к решению бизнес-задач: вижу рутину, нахожу узкое место и автоматизирую процесс, сокращая время выполнения задачи в десятки раз. Здесь представлены два макроса, которые я разработал для реальной ежедневной работы.

---

## 📁 Макрос 1: Очистка и подготовка прайс-листов

### Задача
Ежедневно требовалось многократно обрабатывать прайс-листы: удалять шапку, лишние столбцы, фильтровать данные и форматировать таблицу для загрузки в CRM Moby-C.  
**Ручная обработка занимала 2 минуты** на один файл, и такая задача повторялась до 20 раз в день.

### Решение
Разработал макрос `Очистка_Прайса`, который автоматически выполняет все действия одним нажатием клавиш за **5 секунд**.

### Результат
- Время обработки: **2 минуты → 5 секунд** (ускорение в **24 раза**)
- Ручных действий: **6–8 шагов → 1 шаг** (горячая клавиша)
- Ошибки: **исключены**
- Экономия времени: до **40 минут/день**

**Файл:** [`Макрос подготовка прайса.bas`](Макрос%20подготовка%20прайса.bas)  
**Горячая клавиша:** `Ctrl + Shift + L`

## 📁 Макрос 2: Автоматизация маркировки акций и новинок

### Задача
После подготовки прайс-листа требовалось вручную:
1. Удалить эксклюзивные товары ("Мит Гарден") по условиям контракта
2. Выделить акции (жёлтым) и новинки бренда (зелёным)
3. Сохранить файл для рассылки клиентам

**Ручная обработка занимала 3–5 минут** и была подвержена ошибкам из-за человеческого фактора.

### Решение
Разработал макрос `Выделение_акций`, который выполняет все эти действия за **3 секунды** с абсолютной точностью.

### Результат
- Время обработки: **3–5 минут → 3 секунды** (ускорение в **60–100 раз**)
- Ручных действий: **5–7 шагов → 1 шаг** (горячая клавиша)
- Пропуски акций: **исключены**
- Ошибки удаления: **исключены**
- Экономия времени: до **30 минут/неделя**

**Файл:** [`Макрос Выделение акций.bas`](Макрос%20Выделение%20акций.bas)  
**Горячая клавиша:** `Ctrl + Shift + K`
