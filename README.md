### Проект №1. Очистка и подготовка прайс-листов

**Задача:**  
Ежедневно и многократно требовалось обрабатывать прайс-листы: удалять шапку, лишние столбцы, фильтровать данные и форматировать таблицу для ручной выбивки заказа в CRM-систему **MobyC**.

**Решение:**  
Разработан макрос `Очистка_Прайса`, который автоматически выполняет все действия за 5 секунд.

| Шаг | Действие | Результат |
|-----|----------|-----------|
| 1 | Удаляет строки 1–10 | Остаются только данные |
| 2 | Удаляет столбцы D и E | Убирает единицы измерения и пустые столбцы |
| 3 | Сокращает ширину столбца B на 35% | Компактное отображение артикулов |
| 4 | Удаляет пустые строки в столбце D | Остаются только строки с отметками |
| 5 | Автоподбор ширины столбца D | Чёткое отображение отметок |
| 6 | Масштаб 150% | Удобный просмотр |
| 7 | Выравнивает цены в столбце C по правому краю | Стандартный формат цен |
| 8 | Курсор на B2 | Готовность к работе |
| 9 | Сообщение "Готово!" | Информирование о завершении |

**Горячая клавиша:** `Ctrl + Shift + L` (Win) / `Cmd + Shift + L` (Mac)

**Результат:**
- ✅ Время обработки: **2 минуты → 5 секунд**
- ✅ Ручных действий: **8 шагов → 1 шаг**
- ✅ Экономия: **до 1 часа в неделю**

### Проект №2. Выделение акций и новинок в прайс-листах

**Задача:**  
После подготовки прайс-листа требовалось:
1. Удалить товары с эксклюзивным контрактом ("Мит Гарден")
2. Выделить акционные товары жёлтым цветом
3. Выделить новинки (бренд "Джавс") зелёным цветом
4. Сохранить файл для рассылки клиентам

**Решение:**  
Разработан макрос `Выделение_акций`, который автоматически выполняет все действия за 3 секунды.

| Условие | Действие | Цвет |
|---------|----------|------|
| "Мит Гарден" в столбце B | Удалить строку | — |
| Столбец C пустой | Пропустить (не выделять) | — |
| Столбец C = 21261016 или 00175 | Пропустить (не выделять) | — |
| "Джавс" в столбце B | Выделить ячейку B | 🟩 Светло-зелёный |
| "акция" в столбце B или C | Выделить ячейку B | 🟨 Жёлтый |

**Горячая клавиша:** `Ctrl + Shift + K` (Win) / `Cmd + Shift + K` (Mac)

**Результат:**
- ✅ Время обработки: **3–4 минуты → 3 секунды**
- ✅ Ручных действий: **7 шагов → 1 шаг**
- ✅ Экономия: **до 5 часов в неделю**

### Проект №3. Подготовка отчёта по дебиторской задолженности

**Задача:**  
Регулярно требовалось обрабатывать файл с дебиторской задолженностью:
1. Удалять служебные строки и лишние столбцы
2. Удалять закрытых клиентов
3. Оставлять только корректные суммы долга (в диапазоне от -28 до 30)
4. Визуально выделять все положительные долги

**Решение:**  
Разработан макрос `Обработка_Дебиторки`, который автоматически выполняет все действия за 3 секунды.

| Шаг | Действие | Результат |
|-----|----------|-----------|
| 1 | Удаляет строки 1–3 | Остаются только данные с заголовками |
| 2 | Удаляет столбцы B, D, E, G | Остаются нужные столбцы |
| 3 | Удаляет закрытых клиентов по списку | Исключение клиентов с эксклюзивным контрактом |
| 4 | Удаляет строки с C < -28 или C > 30 | Остаются только корректные суммы долга |
| 5 | Выделяет строки (A, B, C) светло-красным, если C > 0 | Визуальное выделение всех клиентов с долгом |
| 6 | Подгоняет ширину столбца B | Удобный просмотр |
| 7 | Масштаб 150% | Комфортная работа с отчётом |
| 8 | Курсор на A1 | Готовность к работе |
| 9 | Сообщение "Готово!" | Информирование о завершении |

**Список закрытых клиентов:** Б2693, 01063, A1001, A0145, 03665, Б6926, Б7092, 03286, 05752

**Горячая клавиша:** `Ctrl + Shift + J` (Win) / `Cmd + Shift + J` (Mac)

**Результат:**
- ✅ Время обработки: **5–7 минут → 3 секунды**
- ✅ Ручных действий: **10 шагов → 1 шаг**
- ✅ Экономия: **до 25 минут в неделю**
